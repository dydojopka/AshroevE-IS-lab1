## Контрольные вопросы:


### 1. Представить сходство и отличия одноключевых блочных шифров.

__Сходство:__
- Используют один секретный ключ.
- Работают с блоками фиксированной длины.
- Каждый блок шифруется отдельно.
- Для шифрования и расшифрования используется один и тот же ключ.

__Отличия:__
- В шифрах перестановки меняется порядок символов.
- В шифрах замены символы заменяются другими.
- В составных шифрах используются оба принципа.
- Отличаются способом задания ключа (числовой, словесный, размер таблицы).

### 2. Что определяет выбор размерности таблицы.

Размерность таблицы определяется:
- длиной ключа,
- длиной блока,
- удобством реализации,
- требуемым уровнем криптостойкости.

Количество строк и столбцов должно позволять разместить весь текст (при необходимости дополняется символами).

### 3. Для чего нужно ключевое слово?

Ключевое слово:
- задаёт порядок перестановки столбцов,
- позволяет легко запомнить ключ,
- повышает удобство использования,
- определяет числовой порядок перестановки букв,
- влияет на итоговый шифротекст.

### 1. Используя простейший шифр перестановки зашифровать следующий текст: «Безопасность - это самая опасная иллюзия». Размеры таблицы задайте самостоятельно. 

[Исходный код программы:](task1.py)
```Py
import re

text = "Безопасность - это самая опасная иллюзия"
rows = 5
cols = 8

# Оставляем только буквы и делаем их заглавными
clean_text = re.sub(r'[^а-яА-ЯёЁ]', '', text).upper()
print(f"Очищенный текст: {clean_text}")

# Если букв меньше, чем ячеек (rows * cols), добавляем 'Х'
while len(clean_text) < rows * cols:
    clean_text += "Х"

# Создание и заполнение таблицы
table = [["" for _ in range(cols)] for _ in range(rows)]

# Заполняем таблицу ПО СТОЛБЦАМ
index = 0
for c in range(cols):
    for r in range(rows):
        table[r][c] = clean_text[index]
        index += 1

# Вывод таблицы(для наглядности)
print(f"\nЗаполнение таблицы ({rows}x{cols}) по столбцам:")
print("-" * (cols * 4 + 1))
for row in table:
    print("| " + " | ".join(row) + " |")
print("-" * (cols * 4 + 1))

# Считывание зашифрованного текста ПО СТРОКАМ
cipher_text = ""
for r in range(rows):
    for c in range(cols):
        cipher_text += table[r][c]

print("\nРезультат (считывание по строкам):")
print(cipher_text)
```

### 2. Используя шифр простой перестановки зашифровать вышеприведенный текст. Размер блока 6, ключевое слово придумать самостоятельно.

[Исходный код программы:](task2.py)
```Py
import re

text = "Безопасность - это самая опасная иллюзия"
keyword = "ЛИНУКС" # i use arch btw
block_size = 6

# Убираем всё, кроме русских букв, и переводим в верхний регистр
clean_text = re.sub(r'[^а-яА-ЯёЁ]', '', text).upper()

# Дополняем текст буквой 'Х', если он не делится на размер блока
while len(clean_text) % block_size != 0:
    clean_text += "Х"

# Нужно пронумеровать буквы слова по их порядку в алфавите
chars = []
for i in range(len(keyword)):
    chars.append([keyword[i], i])

# Сортируем буквы по алфавиту
chars.sort()

# Создаем список-ключ, где для каждой позиции буквы в слове записан её алфавитный ранг
key = [0] * block_size
for rank in range(len(chars)):
    alphabet_order = rank + 1 # Порядковый номер в алфавите (от 1 до 6)
    original_index = chars[rank][1]
    key[original_index] = alphabet_order

print(f"Ключевое слово: {keyword}")
print(f"Числовой ключ:  {key}")
print(f"Подготовленный текст: {clean_text}\n")

# Процесс шифрования по блокам
print("-" * 40)
print(f"{'Открытый блок':<15} | {'Зашифрованный блок'}")
print("-" * 40)

encrypted_text = ""

# Режем текст на куски по 6 символов
for i in range(0, len(clean_text), block_size):
    block = clean_text[i : i + block_size]
    cipher_block = ""
    
    # Переставляем буквы внутри блока согласно ключу
    for k in key:
        index_in_block = k - 1
        cipher_block += block[index_in_block]
        
    encrypted_text += cipher_block
    print(f"{block:<15} | {cipher_block}")

print("-" * 40)

print("\nИтоговый зашифрованный текст:")
print(encrypted_text)
```

### 3. Используя прежнее ключевое слово, зашифруйте ту же фразу с помощью таблицы.

[Исходный код программы:](task3.py)
```Py
import re

text = "Безопасность - это самая опасная иллюзия"
keyword = "ЛИНУКС" 

# Подготовка текста
clean_text = re.sub(r'[^а-яА-ЯёЁ]', '', text).upper()
cols = len(keyword)
rows = (len(clean_text) + cols - 1) // cols  # Вычисляем нужное кол-во строк

# Дополняем текст, чтобы таблица была полной
while len(clean_text) < rows * cols:
    clean_text += "Ъ"

# Создаем порядок перестановки
indexed_keyword = []
for i, char in enumerate(keyword):
    indexed_keyword.append((char, i))

# Сортируем по буквам
indexed_keyword.sort()

# Вычисляем порядок столбцов
column_order = []
for char, original_index in indexed_keyword:
    column_order.append(original_index)

print(f"Алфавитный порядок столбцов слова {keyword}: {column_order}\n")

# Заполняем исходную таблицу ПО СТОЛБЦАМ
source_table = [["" for _ in range(cols)] for _ in range(rows)]
index = 0
for c in range(cols):
    for r in range(rows):
        source_table[r][c] = clean_text[index]
        index += 1

# Создаем НОВУЮ таблицу с переставленными столбцами
final_table = [["" for _ in range(cols)] for _ in range(rows)]
for new_idx, old_idx in enumerate(column_order):
    for r in range(rows):
        final_table[r][new_idx] = source_table[r][old_idx]

# Вывод итоговой таблицы
print("Таблица после перестановки столбцов:")
print("-" * (cols * 4 + 1))
for row in final_table:
    print("| " + " | ".join(row) + " |")
print("-" * (cols * 4 + 1))

# Считывание результата ПО СТРОКАМ
cipher_text = ""
for r in range(rows):
    for c in range(cols):
        cipher_text += final_table[r][c]

print("\nЗашифрованный текст:")
print(cipher_text)
```

### 4. Зашифровать вышеприведенную фразу с использованием «магических квадратов» «Магический квадрат» можно использовать любой размерности, в том числе придуманный самостоятельно.

[Исходный код программы:](task4.py)
```Py
import re

text = "Безопасность - это самая опасная иллюзия"

# Подготовка текста
clean_text = re.sub(r'[^а-яА-ЯёЁ]', '', text).upper()

# Для квадрата 6x6 нам нужно ровно 36 символов
while len(clean_text) < 36:
    clean_text += "X"
# Если текст длиннее - обрезаем его до 36
clean_text = clean_text[:36]

print(f"Очищенный текст (36 букв): {clean_text}\n")

# Определяем магический квадрат 6x6 (сумма = 111)
magic_square = [
    [35,  1,  6, 26, 19, 24],
    [ 3, 32,  7, 21, 23, 25],
    [31,  9,  2, 22, 27, 20],
    [ 8, 28, 33, 17, 10, 15],
    [30,  5, 34, 12, 14, 16],
    [ 4, 36, 29, 13, 18, 11]
]

# Таблица для расстановки букв
table = [["" for _ in range(6)] for _ in range(6)]

# Идем по числам от 1 до 36
for number in range(1, 37):
    # Находим, в какой строке (r) и столбце (c) стоит это число в магическом квадрате
    found = False
    for r in range(6):
        for c in range(6):
            if magic_square[r][c] == number:
                # Берем букву из текста с индексом (число - 1) и кладем в таблицу
                table[r][c] = clean_text[number - 1]
                found = True
                break
        if found: break

# Вывод таблицы
print("Таблица, заполненная по магическому квадрату:")
print("-" * 25)
for row in table:
    print("| " + " | ".join(row) + " |")
print("-" * 25)

# Считываем результат ПО СТРОКАМ
cipher_text = ""
for r in range(6):
    for c in range(6):
        cipher_text += table[r][c]

print("\nЗашифрованный текст:")
print(cipher_text)
```

### 5. Определите ключи шифра Цезаря, если известны следующие пары открытый текст - шифротекст (исходный алфавит: `АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ`): `АПЕЛЬСИН - ТВЧЮОДЫА`; `МАНДАРИН - ТЁУЙЁЦОУ`

[Исходный код программы:](task5.py)
```Py
alphabet = "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"

# Пары для анализа
pairs = [
    ("АПЕЛЬСИН", "ТВЧЮОДЫА"),
    ("МАНДАРИН", "ТЁУЙЁЦОУ")
]

for plain, cipher in pairs:
    print(f"Анализ пары: {plain} - {cipher}")
    
    # Берем первые буквы
    char_p = plain[0]
    char_c = cipher[0]
    
    # Находим их позиции в алфавите
    pos_p = alphabet.find(char_p)
    pos_c = alphabet.find(char_c)
    
    # Вычисляем сдвиг (n)
    # Если позиция шифробуквы меньше, добавляем длину алфавита (циклический сдвиг)
    n = (pos_c - pos_p) % len(alphabet)
    
    print(f"1. Буква '{char_p}' (позиция {pos_p}) стала '{char_c}' (позиция {pos_c})")
    print(f"2. Вычисленный ключ (сдвиг n) = {n}")
    
    # Проверка по второй букве
    test_pos = (alphabet.find(plain[1]) + n) % len(alphabet)
    if alphabet[test_pos] == cipher[1]:
        print(f"3. Проверка пройдена: для второй буквы ключ тоже подходит.")
    
    print("-" * 30)
```

### 6. Расшифруйте следующие сообщения, зашифрованные шифром Цезаря, и определите ключ n, `0<n< 33`, если известно, что исходные сообщения составлены из алфавита `АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ`: `ЮВПЛШУХ`; `СФЫЮБШЯФУ`

[Исходный код программы:](task6.py)
```Py
alphabet = "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"

# Зашифрованные сообщения
encrypted_messages = [
    "ЮВПЛШУХ",
    "СФЫЮБШЯФУ"
]

# Перебираем возможные ключи
for n in range(1, len(alphabet)):
    print(f"Ключ n = {n}")
    
    for message in encrypted_messages:
        decrypted = ""
        
        for char in message:
            # Находим позицию буквы
            pos = alphabet.find(char)
            
            # Расшифровка (сдвиг назад)
            new_pos = (pos - n) % len(alphabet)
            decrypted += alphabet[new_pos]
        
        print(f"{message} -> {decrypted}")
    
    print("-" * 40)
```
